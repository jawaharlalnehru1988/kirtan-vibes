# Kirtan Vibes — Handcrafted Mridanga & Kirtan Academy

A production-ready **Next.js 16** (App Router) web application created from Google Stitch design exports for **Kirtan Vibes by Sri Ganapathi Prabhu**.

---

## 🌟 Overview & Routes

- **Home Page (`/`)**: High-class hand-tuned Bengali mridangas & fiberglass khols, interactive Web Audio tone previewer, craftsmanship comparisons, devotional sangha testimonials, and studio contact.
- **Instruments & Shop (`/instruments`)**: Full catalog of terracotta clay khols, all-weather fiberglass drums, pure bell-metal (kansa) karatals, embroidered cotton straps, padded traveling bags, and spare heads with scale tuning filters.
- **Academy & Tutorials (`/tutorials`)**: Online & in-studio workshops with Sri Ganapathi Prabhu, Bengali bol syllabuses, lesson packages (Diksha, Intermediate Accompaniment, Master Parampara), repair & tuning workshop guides.
- **Sacred Cart & Transit (`/cart`)**: Consecrated cart review, live quantity adjustments, add-on care kits, express doorstep delivery / temple pickup options, transit insurance details, and WhatsApp / online checkout.
- **About Sri Ganapathi Prabhu (`/about`)**: Artisanal parampara heritage, 20+ years of devotional craftsmanship, The 4 Sacred Pillars of Craftsmanship, and SMVT Bangalore workshop visit instructions.

---

## 🎨 Design System ("Vedic Sacred Elegance")

Configured with **Tailwind CSS v4** `@theme` tokens matching Google Stitch specifications:
- **Palette**: Sacred Terracotta (`primary: #6b1d10`, `primary-container: #8a3324`), Devotional Saffron/Gold (`secondary: #a23f00`, `secondary-container: #fc7127`, `tertiary-fixed: #ffddb9`), Temple Sandstone (`surface: #fff8f6`, `surface-container: #ffe9e2`).
- **Typography**: `Playfair Display` for classical headlines & hero displays, `Plus Jakarta Sans` for clean, legible body text and devotional UI labels.
- **Icons**: Material Symbols Outlined.

## 🚀 Getting Started

To run the development server locally:

```bash
cd D:\projects\kirtan-vibes
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

To build for production:

```bash
npm run build
npm start
```
